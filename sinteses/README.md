# sinteses

Derivados de modelo: resumos, comparações, notas de estudo. Uma síntese nunca é fonte e nunca é citada como tal.

Regras:

- cada arquivo começa com frontmatter que declara `derivado: true`, o modelo, a data e as fontes de que deriva;
- cada afirmação aponta para a âncora da fonte que a sustenta, no formato `fontes/<dominio>/<id>/texto.md#<ancora>`;
- afirmação sem âncora é juízo do modelo e vem marcada como tal;
- nenhuma síntese altera, substitui ou reproduz além do necessário o texto de uma fonte protegida.
